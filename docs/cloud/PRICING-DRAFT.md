# Pricing draft (internal — not a public promise)

Last updated: 2026-10-11 · Track: `cloud`

Numbers are **starting hypotheses** for Chainepic LTD. Adjust after first 3 Setup deals.

## Principles

1. Self-host MIT remains fully capable for sync + rules + digest.  
2. Price **operations and time**, not “ability to call GSC”.  
3. AI is optional add-on; rules stay free everywhere.

## Offers

| Offer | Price (draft) | Includes | Does not include |
| --- | --- | --- | --- |
| **Self-host** | $0 | Everything in GitHub MIT | We do not run your server |
| **Setup** | $199–$499 one-time | Connect engines, select properties, first sync, 30-min walkthrough | Ongoing hosting |
| **Cloud Solo** | $19–$29 / mo | We host one instance, updates, backups, email digest optional | Agency multi-client |
| **Cloud Agency** | $79–$149 / mo | Multi-client workspaces (when built), seats, priority email | Custom on-prem |
| **AI Assist** | Usage or pack | Narrated digests / polish via Chainepic meter | Required for core sync |
| **Priority support** | +$49 / mo or bundled | SLA response window | Feature guarantees |

## Launch sequence (cash first)

1. Sell **Setup** while Cloud is still “we provision a VPS for you”.  
2. Convert Setup clients who hate ops → **Cloud Solo** (manual instance OK).  
3. Build true multi-tenant only after ≥3 Agency conversations.

## Explicit non-goals for v1 pricing

- Charging for number of webmaster engines connected  
- Charging for rule-based recommendations  
- Requiring Cloud to use Docker locally
