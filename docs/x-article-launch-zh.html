最近一个站长面板开源杀疯了，出海站长都在抢着求更新

Google + Bing + Yandex 三条官方 API 装进一个自托管面板。密钥不出本机，群里已经在互相安利、催下个版本。

做出海站的都懂：早上一睁眼，先开 Google Search Console，再开 Bing Webmaster， 俄语区还得再开一遍 Yandex。三个后台、三套数字、同一份焦虑。

最近圈子里疯传一个开源项目：把三家站长数据拉到同一块面板里，同步大约 28 天指标，标出变动， 还能每天把 Markdown / JSON 日报推到 webhook 或邮箱。MIT，自托管，维护方是 Chainepic LTD。

GitHub： github.com/chainepic/gsc-bing-yandex-dashboard

为什么站长宁可自托管，也不愿再交钥匙？

市面上那些「统一 SEO 看板」，套路差不多：把你的 Search Console OAuth、Bing API key 交到他们云上。 大厂营销团队或许无所谓；管几十个站、或者根本不想再多一个握流量数据的供应商——直接拒。

这个项目踩的是另一条路，也是它传得快的原因：

  • 只对接 官方 GSC / Bing / Yandex API
  • 指标存在本地 SQLite 文件里
  • 用你自己的 APP_SECRET 加密密钥（AES-256-GCM）
  • 公网可设面板密码；localhost 默认开放

升级就是 git pull。数据在 ./data。不上云、不经过中间人——所以大家才敢真装。

先看长什么样（中文界面）

总览页：各引擎 KPI、火花线、周 / 28 天对比、覆盖缺口和关注列表——不用在三个后台之间跳。

站点页并排展示周点击和周环比，以及某引擎缺失或骤降的位置。

关键词跨引擎统一：查询词、主机、点击、展示、排名和变化，带客户端筛选（骤降、「展示↑ / 点击↓」等）。

点进某个主机，切换引擎标签看趋势、查询词变动和页面变动。

真正让人上头的，是早报

很多站长不是缺看板，是缺一份「睁眼就能看」的东西。 这面板默认每天早上（你时区 09:00）先同步、再出日报，经 webhook 或 SMTP 推出去；也可以在「日报」页随时手搓一份。

装起来有多快？

四步向导。Google / Bing / Yandex 任意接——一家也行，三家更香——勾选资源、点同步就完事。 界面自带 中英文，出海团队不用再自己翻译。

本地开箱大概就这几步：

  • pnpm install
  • 在 apps/web/.env 里设一个强 APP_SECRET
  • pnpm dev → 打开 http://localhost:3847/setup
  • 嫌麻烦就 Docker Compose 一条龙

免费到什么程度？

自托管整包是 MIT：同步、变动、日报、规则建议，全在你机器上跑。 官方文档里写了以后可能有可选托管云和按量 AI——但开源版本身不依赖这些。 细节在仓库 docs/OPEN-CORE.md。

为什么出海站长扎堆？

  • 天天泡 Search Console 的独立开发 / 运营
  • 还要盯 Bing（甚至 Yandex）的代理商、多站组合
  • 想要一份早报，而不是三个浏览器标签
  • 死活不愿把站长凭证再贴进另一家 SaaS

说清楚：它不是 Ahrefs、Semrush，也不是关键词研究套件。 就是一层薄控制台，盖在你本来就拥有的官方站长数据上——所以传得快、也装得放心。
